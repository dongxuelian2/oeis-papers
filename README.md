# OEIS papers

Mathematical papers and research notes, ordered by OEIS sequence number. Each entry retains the sequence's OEIS description and briefly states the mathematical result established by its accompanying manuscript. Sequences treated in the same paper are grouped together.

- **[A001040 / A001053](papers/A001040-A001053/)**
  - **Result:** Proves Kurkov's two rook-tour conjectures: the numbers of directed Hamiltonian tours on a two-column board with endpoints in opposite or equal columns are `2n! A001040(n)` and `2n! A001053(n)`, respectively.
  - [A001040](https://oeis.org/A001040): a(n+1) = n*a(n) + a(n-1) with a(0)=0, a(1)=1.
  - [A001053](https://oeis.org/A001053): a(n+1) = n*a(n) + a(n-1) with a(0)=1, a(1)=0.
  - **Our result:** We proved Kurkov's endpoint-refined rook-tour conjectures for every positive board size: the numbers of directed Hamilton tours with endpoints in opposite and equal columns are respectively `2*n!*A001040(n)` and `2*n!*A001053(n)`.

- **[A006063 / A096680 / A096904](papers/A006063/)**
  - **Result:** Classifies the sizes admitting cube-sum permutations: existence for every `n >= 173`, with the finite exceptions below 173 determined; establishes eventual multiplicity and constructs fixed-point-controlled involutions for sufficiently large sizes.
  - [A006063](https://oeis.org/A006063): Values of n admitting a permutation of 1, ..., n such that i + p_i is a cube for every i.
  - [A096680](https://oeis.org/A096680): Values of n admitting more than one such cube-sum permutation.
  - [A096904](https://oeis.org/A096904): Number of such permutations for each n.
  - **Our result:** We proved the exact existence classification of cube-sum permutations: `P(n)>0` for every `n>=173`, with precisely 48 admissible smaller sizes, and `P(n)>=3` for every `n>=175`. Consequently `A006063(j)=j+124` for `j>=49` and `A096680(j)=j+161` for `j>=14`; the finite base cases have explicit certificates. We also constructed eventual one-fixed-point and fixed-point-free cube-sum involutions.
